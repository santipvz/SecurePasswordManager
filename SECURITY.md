# Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/santipvz/SecurePasswordManager/security/advisories/new). Include the affected version, operating system, steps to reproduce, and expected impact. Use a synthetic vault and redact secrets, PINs, personal data, and real vault contents.

Maintainers can use the private advisory to coordinate a fix and disclosure. The [desktop threat model](THREAT_MODEL.md) describes the intended protections and release checks.
